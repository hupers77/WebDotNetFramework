# 점검 항목과 확인 방법

기준:

1. 「주요정보통신기반시설 기술적 취약점 분석·평가 방법 상세가이드」 웹 애플리케이션 21개 항목(2021, 이하 주통기반)
2. 행정안전부·KISA 「소프트웨어 보안약점 진단가이드」 49개 항목(2021)
3. 보호나라(KISA) 홈페이지 보안 자가점검 권고
4. OWASP Top 10 (2021)
5. 「개인정보의 안전성 확보조치 기준」

판정은 양호 / 취약(조치) / 권고 / 운영 확인 / 해당 없음 중 하나를 쓴다. "자동"은 `scripts/`의 도구가 후보를 보여 주는 항목이다.

## 5. 스크립트가 없을 때 쓰는 명령

```bash
# 취약 패키지
dotnet list <솔루션>.sln package --vulnerable --include-transitive
npm audit --omit=dev
pip-audit            # pip install pip-audit
composer audit
# Java: OWASP Dependency-Check (mvn org.owasp:dependency-check-maven:check)

# 헤더·쿠키
curl -sI https://대상/            # Server, X-Powered-By, HSTS, CSP, Set-Cookie
curl -s -o /dev/null -w "%{http_code}\n" -X TRACE https://대상/   # 405/501 기대
curl -s -o /dev/null -w "%{http_code}\n" https://대상/.git/HEAD    # 404 기대
```
