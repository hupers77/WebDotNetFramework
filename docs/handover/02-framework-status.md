# 02. 프레임워크 구현 현황

기준 시점: 2026-10-23 (`main` `2e31ad4`, PR #56까지). 프레임워크는 아직 3단계 진행 중입니다. 업무 저장소를 만들기 전에 이 표를 최신으로 고칩니다(README "갱신 방법").

표기: **완료** = `main`에 병합, **설계만** = 설계서에만 있고 코드 없음, **예정** = 로드맵에 있으나 설계 세부도 미정.

## 1. 단계

| 단계 | 범위 | 상태 |
| --- | --- | --- |
| 1단계 기반 | 솔루션 구조, SpExecutor, ID/PW 로그인, 권한·메뉴, 레이아웃·메뉴 트리·멀티 탭, 공통코드, 다국어, 설정, 로그 | 완료 (2026-10-22, 관문: 표준 화면 2개 + 권한 매트릭스 테스트) |
| 2단계 연계 | 파일, 엑셀, 협력사 가입·승인·MFA, 메일·알림, 스케줄러(Portal.Worker), 사용자·회사·부서·역할·권한 관리, 로그 조회·배치, 레포트·PDF·인쇄, 이메일 OTP | 완료 (2026-10-23, 단계 종료 통합 테스트 통과) |
| 3단계 업무 공통 | 협력사 전용 로그인, 게시판, 대시보드, 기준정보(휴일 등)·공통 팝업, 외부 API 수신/송신, LDAP 모듈, AD SSO (전자결재 골격·AD 조직 동기화는 범위에서 제외, 2026-10-23) | **진행 중** |
| 4단계 안정화 | 모의 해킹, 부하 테스트, 매뉴얼, 배포 자동화 | 예정 |

사용자 결정: 업무 개발이 시작되면 프레임워크 기반 단계 작업은 마무리하고 다음 단계로 넘어갑니다.

## 3. 업무 개발 전에 남은 프레임워크 확인 사항

- 단계 종료 통합 테스트 확인 목록(공유 폴더 `notes/integration-check-list.md`)의 "대기" 항목: 운영 첫 배포 때 계정 배치가 한꺼번에 안내 메일을 보낼 수 있음, DB 서버 시간대, IIS 앱 풀 계정에서 Edge 헤드리스 실행, 서버 한국어·중국어 글꼴 등.
- 개인정보 화면의 `PII_YN` 시드가 모두 `N`: 사용자 관리 등 개인정보 화면을 `Y`로 바꿀지 결정 필요.
- 중국어는 간체(`zh-CN`)로 가정했고 아직 확정되지 않았습니다.
